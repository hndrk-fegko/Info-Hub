# Manual E2E Scenarios

Diese Dateien beschreiben produktionsnahe Browser-Szenarien, die aktuell noch manuell ausgefuehrt werden.

Aufruf ueber den zentralen Runner:

```bash
php tests/run.php --suite=e2e
```

Der Runner listet die Schritte und den Dateipfad; die eigentliche Browser-Ausfuehrung bleibt bewusst manuell.
